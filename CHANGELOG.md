# Changelog

## 0.4.0

- Add a clickable `Dialect: xxx` status bar selector for SQL editors.
- Add the `Omni SQL Formatter: change dialect` command with the current dialect listed first.
- Save dialect selections to workspace folder settings, or user settings when no workspace is open.
- Refresh the displayed dialect when the active editor or configuration changes.

## 0.3.0

- Recognize assignment-style and optimizer SELECT hints.
- Configure hint placement and content formatting.
- Preserve quoted strings, unknown hint syntax and Python tuple trailing commas.
- Add Marketplace publishing instructions.

## 0.2.0

- Add grouped settings for casing, word lists, line breaks, indentation and dialects.
- Support comma-separated, case-insensitive include/exclude lists.

## 0.1.0

- Initial PostgreSQL formatter extension with CASE and nested-query layouts.
